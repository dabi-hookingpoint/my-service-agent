트레이스 03 — 경계 경로 (필수 인자 누락 → 되묻기 → 실제 접수)
실행: 실제 tools.py 호출 (LLM 미사용, 에이전트 역할은 Claude가 직접 수행)
2턴짜리 대화. MISSING_ARG 상황에서 "부분 인자로 도구를 호출하지 않는다"(④)는 규칙을 실제로 지켰는지 확인하는 트레이스.

--- 턴 A ---

요청:
"제작 협업 문의를 넣고 싶어요. 신작 다큐멘터리 공동제작을 제안드리고 싶습니다."

선택한 도구:
없음 — category(제작)와 message(다큐멘터리 공동제작 제안)는 있지만 contact_email이 없어서
submit_inquiry를 부분 인자로 호출하지 않고 먼저 되묻는다 (design-packet.md ④ MISSING_ARG 규칙).

인자:
(도구 호출 안 함)

반환 근거:
(도구 호출 안 함 — 해당 없음)

최종 답:
"신작 다큐멘터리 공동제작 제안, 잘 받았어요! 접수해드리려면 회신받으실 이메일 주소가 필요해요. 알려주시겠어요?"

중단·이관 이유:
MISSING_ARG (contact_email 누락) — 도구 호출 전에 사용자에게 추가 질문

--- 턴 B ---

요청:
"collab@partnerstudio.com 입니다."

선택한 도구:
submit_inquiry
(호출 전, 사용자에게 접수 내용 요약 — "제작 카테고리 / collab@partnerstudio.com / '신작 다큐멘터리 공동제작을 제안드리고 싶습니다.' 이대로 접수할까요?" — 확인을 받았다고 가정. ③ 권한과 승인: 쓰기 도구는 실행 전 사용자 확인 필수)

인자:
{"category": "제작", "contact_email": "collab@partnerstudio.com", "message": "신작 다큐멘터리 공동제작을 제안드리고 싶습니다."}

반환 근거 (tools.py 실제 실행 결과 — my-agent/data/inquiries.log.json에 실제로 기록됨):
{
  "inquiry_id": "inq-473280c7",
  "status": "접수됨",
  "expected_response": "영업일 기준 2~3일"
}

최종 답:
"접수 완료했어요 (접수번호 inq-473280c7). 영업일 기준 2~3일 안에 담당자가 회신드릴 거예요."

중단·이관 이유:
없음 (정상 접수). 승인/확정 상태는 아니며, 반환값에도 "접수됨"만 있고 "승인"은 없음 — 담당자 처리 대상으로 남음.
